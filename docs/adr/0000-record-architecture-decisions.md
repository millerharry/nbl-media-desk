# 0000. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-08

## Context
This is an open-source project meant to be read and extended by others. Reviewers and contributors need to know *why* the system looks the way it does, not just what it does.

## Decision
Record each significant decision as an ADR in `docs/adr/`, numbered sequentially, in the Nygard format (Context, Decision, Consequences, Alternatives).

## Consequences
Decisions are reviewable in PRs and searchable later. Small overhead per decision.
